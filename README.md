# CondoFácil

Protótipo acadêmico de uma aplicação web para moradores de um condomínio.

Tecnologias:
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Teste

Abra o arquivo `index.html` no navegador.

Os botões de navegação usam links HTML (`href="#..."`), portanto funcionam mesmo abrindo o arquivo diretamente no navegador.

O contato e a publicação de anúncios são simulações feitas com JavaScript.

Ainda não existe banco de dados, login real ou servidor.
